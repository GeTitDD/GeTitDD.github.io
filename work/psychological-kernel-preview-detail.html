面向游戏角色演进的
轻量状态建模与机制响应检验

背景 · 游戏角色系统需要程序可解析的结构化状态量，也需要区分不同人设在同一事件下的响应。仅生成听起来合理的描述，或输出格式合法的 JSON，都不足以证明相关心理机制已被有效建模。

研究问题 · 0.8B 量级的轻量模型，能否在保持固定 JSON 输出契约的同时，对自我效能、可用精力、自主关切（自主优先级）与注意占用等关键输入变化，给出幅值充分、方向合理且稳定的状态响应？

研究方法 · 对 Qwen3.5-0.8B 开展 LoRA 微调，使用 640 条父家族隔离训练样本、单 seed 0 与 120 个优化步。依据 80 条固定验证输入选择第 2 轮检查点，再以 220 条历史确认输入检验九轴输出和机制响应，另以 16 条无约束诊断补充格式证据。

主要发现 · 220/220 条受约束确认输入与 16/16 条无约束诊断均输出合法完整 JSON；但自我效能曲线稳定性仅为 37.5%，自主优先级的可见响应与趋势均为零，未达到轻量模型工程迁移标准。

结论与边界 · 本轮打通结构化生成与分层诊断链路，尚不能支持心理有效性或游戏适配。工程迁移维持 REJECT，心理有效性维持 INCONCLUSIVE。确认集曾参与历史流程；合成 Agent 参考不是独立人类心理真值，新旧基座比较也不构成严格同条件的规模消融。

图解摘要 / GRAPHICAL ABSTRACT

数值跳动只是表象，
方向与单调性才是真考题。

以“设备传动带损坏”为例：在零件、说明书与技术支持相同的条件下，不同自我效能输入应当对应不同的主观应对判断。本研究检验这种受控变化下的状态响应，而不只是能否生成一份格式完整的输出。

格式这一层

能不能把表填完整？

本轮确认输入的结构输出符合约定，固定字段与数值可由程序读取；这提供接口格式证据。

机制这一层

输入变了，反应对不对？

部分案例出现方向响应，部分输入变化仍未带来足够幅值；曲线稳定也可能只是没有响应，需要结合可见响应与趋势判断。

应用这一层

能不能用于真实角色？

下游适配仍须通过机制响应与行为验证；本轮候选因关键响应和稳定性缺口未获采用。

行为响应 / 有局部缺口

自我效能曲线稳定性从参照的 100% 降为 37.5%；自主关切的可见响应与趋势均为零。

应用决策 / 候选未采用

保留游戏适配门槛

未放宽标准或追加调参。游戏适配与下游行为收益尚未验证，不把结构化输出当作角色能力的最终证明。

从“说得像”，
走向可检查的状态。

游戏角色状态中间件需要兼顾结构确定性与输入敏感度。研究将评测拆为三个递进层：能否遵循 JSON 接口契约、是否响应角色特征，以及响应的幅度与稳定性是否足以支撑下游使用。

  1. 固定情境，只改变自我效能、精力、自主关切或注意占用，输出是否产生足够且方向正确的变化？
  2. 应保持不变的轴能否稳定，相关轴与无关轴能否区分？
  3. 将模型缩小到 0.8B，格式与各机制是否都达到迁移验收要求？

这里只检验模型定义下的条件响应。主观应对潜力不是客观成功率，投入与退出准备度不必互补，抵抗也不等于退出。

CONTRACT / 接口定义

输入事实，输出状态。

01 / CONTEXT

四项事实情境

事件前背景、当前事件、评价目标、比较基准。明确评价的是哪个目标、行动、主张与外部要求。

02 / FEATURES

十二项角色特征

领域自我效能、不确定性容忍、资源与尊重满足、价值优先级，以及事件前情绪、精力和注意占用。未提供值保留 null。

03 / OUTPUT

九轴 0–1 数值

固定字段与定义，可变数值。它们是接口内的状态量，不应整体称作“心理准确率”或获胜概率。

接口字段清单 / 查看输入字段与九轴 JSON key

输入按 pk-fixed-prefix-0.10.0 契约组织；未提供的角色特征使用 null。输出字段定义固定，九轴数值范围为 0–1。

输入 / 情境事实

JSON 字段接口含义
pre_event_background事件前背景事件发生前与当前判断有关的背景。
current_event当前事件正在进行心理状态评估的事件。
evaluation_target评价目标当前事件中被评估的目标、行动或主张。
comparison_baseline比较基准用于界定主观增益与成本的比较参照。

输入 / 角色特征

JSON 字段接口含义
domain_self_efficacy领域自我效能对完成相关领域任务的长期信心，不等同于对当前任务的把握。
uncertainty_tolerance不确定性容忍信息不完整时继续判断或行动的通常意愿。
material_security_fulfillment物质保障满足对基本物质需求能够稳定获得的长期主观满足。
social_respect_fulfillment社会尊重满足感到被他人认可、重视和尊重的长期程度。
safety_priority安全优先级权衡时优先避免伤害损失、保护既有成果的程度。
autonomy_priority自主优先级重视自主决策与选择自由的程度，不描述当前环境是否强迫。
achievement_priority成就优先级重视达成目标、表现良好和证明能力的程度。
concern_for_others对他人的关切权衡时优先考虑他人利益、感受与尊严的程度。
pre_event_pleasantness事件前愉悦感事件发生前即时的愉悦或不愉悦程度。
pre_event_activation事件前激活度事件前的清醒、唤醒与警觉程度，区别于可持续精力。
pre_event_available_energy事件前可用精力事件发生前可用于后续活动的精力储备。
pre_event_mental_occupation事件前注意占用注意力被其他任务或想法占用的程度；值越高，可用注意越少。

输出 / 九轴 JSON

JSON 字段接口含义
goal_relevance目标相关性当前事件对指定目标的重要程度，不代表角色通常有多重视该目标。
perceived_gain主观收益相对比较基准，事件或行动带来的主观额外目标进展。
perceived_cost主观成本相对比较基准，事件或行动造成的主观额外阻碍或损失。
expectancy_violation预期违背事件偏离既有预期的程度，不等同于客观罕见程度。
claim_acceptance主张接受对指定主张的认可程度，不等同于喜欢来源或服从要求。
coping_potential应对潜力当前主观上认为自己能够处理任务的程度，不代表客观可行性。
engagement_readiness投入准备度当前投入指定行动的准备程度，不表示行动已经发生。
withdrawal_readiness退出准备度当前停止或退出行动的准备程度，不必与投入准备度互补。
resistance_readiness抵抗准备度当前反对指定外部要求或安排的准备程度，区别于单纯退出。

契约注记：JSON 中的英文 description 是版本内固定字段定义，不是模型生成的思考链（CoT）；九轴数值属于中间状态估计，不等同于心理真值、分类准确率或获胜概率。

按父家族排除

READING THE RESULT

正在读取对应机制结果…

结构学会了，仍需检查机制。

220/220 条确认输入在结构约束下生成合法完整 JSON；额外 16/16 条无约束格式诊断也全部通过。无约束诊断仅为小样本格式证据，两类结果都不能证明语义与心理有效性。

平均值无法掩盖零响应。

分项诊断显示：自主关切（自主优先级）的可见响应、趋势与调节均为 0，注意占用的可见响应也为 0；自我效能虽有方向响应，曲线稳定性仅为 37.5%。这些机制缺口决定本轮候选不获采用。

让结论有边界。
难点：固定格式掩盖数值学习
将固定前缀与数值 token 的训练损失分开监控，再以受控输入扰动检验响应曲线。合法 JSON 只验收接口格式，不能替代趋势、情境调节与曲线稳定性检查。
难点：训练与选模相互干扰
按父家族排除数据，只用固定验证集选择 epoch。保留第三轮分数下降、确认集历史使用及单 seed 限制；不追加调参追求更好数字。
难点：参考本身不够可靠
合成参考、先验估计和复核不能视为独立心理真值。保留强证据、间接证据与先验类别；后续应补独立参考、未使用的确认集和多训练 seed。
应用决定：不跳过迁移门槛
工程迁移维持 REJECT，心理有效性维持 INCONCLUSIVE。当前尚未证明进入游戏后能够产生可靠 NPC 行为，也不能将“参数更小”等同于“推理更快且能力无损”；按本轮标准，暂不放行候选进入游戏适配试用。
输入映射、九轴系数与具体游戏控制的关系尚待适配验证；本页不展示虚构的 NPC 游戏成绩。
