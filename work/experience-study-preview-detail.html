小模型 Agent：经验外化与内化边界研究

分别评估上下文检索、权重微调与持续更新三条经验路径，在受控任务与实机游戏环境中，以任务结果和行为记录检验收益与边界。

让过往经验真正转化为
小模型 Agent 的行动增量。

背景 · 小模型在受限算力与上下文预算下执行连续决策时，单纯堆叠交互日志并不会自动转化为更优策略，关键在于经验如何被紧凑表征、检索与内化。

研究问题 · 推理前检索外部记忆（外化）与微调更新模型权重（内化），能否各自带来可靠的任务增益？持续引入新经验，又能否驱动稳定的长期能力增长？

研究方法 · 按各分支固定数据快照与评估协议，分别比较外部记忆、参数学习和持续更新；以 mini-tactics 受控任务拆分影响来源，在 2048 与武侠 RPG 中分别检查环境接入、实际行动与局部纠错。

主要发现 · 在受控任务中，紧凑经验条件下的胜利回合从 39/120 提至 99/120，支持冻结基座上的上下文收益。专门 Memory-Aware 训练未识别独有、可靠的增量；自身成功经验 SFT 在三个优化 seed 上均未提升，三轮持续学习候选均被验证门槛拒绝。

游戏实测 · 武侠 RPG 的负经验纠错模型将冗余买粮从 12 次降至 4 次、观察到的消费从 2184 降至 728，并提高可见感悟增量。收益严格限定于一个新世界、一个训练 seed 及 10 天窗口；2048 已完成实机环境接入与单局零样本观察，暂无训练前后提升对照。

结论与边界 · 任务收益取决于经验表征与学习目标，不能将“推理期记忆有效”等同于“模型已将能力内化至权重”。RPG 仅采用等待、参悟、工作、买粮四类高层动作接口：模型选择动作字母，执行器设置参数；完整人类视角 UI 工具链及长期增长尚未验证。

模型学会了经验，
还是只在当前输入里使用它？

长周期运行的 Agent 会积累交互轨迹，但上下文增长、教师信号介入与计算预算差异，都可能造成“模型已经学会”的归因失真。实验需要分别控制和报告这些混杂因素，再判断收益来自哪里。

  1. 冻结权重时，不同经验表示是否带来不同任务收益？
  2. 去掉推理时的记忆后，参数训练能否保留经验收益？
  3. 固定教师 SFT 父模型、增量更新数与处理 token 后，回合奖励学习与继续 SFT 有何差异？
  4. 持续引入新经验后，候选模型能否通过验证并形成增长？
RESEARCH FRAMEWORK / 总体研究框架

拆开经验路径，
统一检验实际行为。

先厘清一个本质差异：推理前检索外部记忆，类似行动前“翻笔记”；通过梯度更新改变模型权重，则尝试把经验内化。两者是不同的经验利用机制，应分别验证。

研究依次审视外部经验检索、权重训练与持续更新候选的验证结果；各分支回到对应的任务指标与可核验行动记录，不把上下文收益直接解释为权重增长。

通过训练学经验

练习不保证学对

本轮三次持续更新候选均未通过验证门槛并被拒绝，因此不能据此宣称模型具备长期自主增长能力。

READING THE RESULT

查看差值、区间与统计限制 ＋

RL 相对配对 SFT：Test 差 +45 个百分点，场景家族聚类 95% 区间 [27.50, 63.33] 个百分点。只覆盖一个训练 seed 下的家族变化，不覆盖训练种子不确定性。

这是探索性比较。预注册主检验是 H1 Memory-Aware 记忆效应、H2 自身成功 SFT 相对 base、H3 最终 Active 相对初始 Active；三项采用 Holm 多重比较校正。不能用有利的次级结果替代主检验。

封存的事后 batch 敏感性分析只有 Test 5 个、OOD 2 个批次：H1 Test p=0.05809419，RL 对配对 SFT Test p=0.05969403。它们保留为弱探索性敏感性结果，不替换原家族分析，也不能证明部署批次不变性。

统计协议与全部限制

先看表示，再看数量。

原始经验组仅为 31/120，低于无记忆基线的 39/120；结构化经验为 70/120，紧凑记忆为 99/120。这一对照提示：在本任务中，不能仅凭经验数量判断收益，还需核对筛选与表征条件。

预算匹配之后，保留边界。

先用教师 SFT 得到 parent731（Test 37/120、OOD 8/48），再分出继续 SFT 与 Episode RL。RL 为 98/120、38/48，配对 SFT 为 44/120、3/48。仅支持这一次教师暖启动后的单种子探索性比较。

专门教模型“利用记忆”，是否额外有效？

Memory-Aware（MA）专项训练未证明相对同预算普通 SFT（NM）的独有、可靠记忆利用收益；不能将冻结基座上的上下文记忆增益，作为专项微调成功的证据。

展开 Memory-Aware 的效应、种子与区间 ＋

预注册 Test 主记忆效应：平均 +5.83 个百分点；三优化 seed 效应为 0 / 0 / +17.5，层级种子 / 家族区间 [0, 17.22] 个百分点。三 seed 共享一次采集快照。

保留条件显著性：家族条件检验原始 p=0.00069993，Holm 校正 p=0.00209979。这不等于训练特有的可靠能力；相对同预算 NM 的记忆效应 DID 为 −19.72 个百分点，层级区间 [−46.67, 2.78] 个百分点。

仅三个优化 seed，且批次敏感性仍存在。结合差值、层级区间与统计协议解释，不单凭一个 p 值判断可靠能力。

怎么改：从复述错误，转向纠错。

从两个训练世界的 48 次 Qwen 自选实测动作中，固定选出 18 次“随身口粮充足却仍实际扣钱采购”的购买经历。纠错组采用条件动作 unlikelihood 训练，直接降低这些动作的概率；不提供正确替代动作。

CE 对照使用完全相同的状态、动作与抽样顺序。两组均为 16 次更新、batch 4、32,832 个优化 token，并使用相同基座 KL 约束 0.1。此处是监督纠错，不是 RL。

CE 对照复述的是同一批有成本的负动作，用于隔离负反馈监督相对模仿同样经历的贡献，不是通用最强 SFT 基线。纠错收益需同时超过未更新基座；当前局部结果满足。

改进成立在哪里？

在不读取外部经验的条件下，纠错模型同时超过未更新基座与同预算模仿组：少买 8 次粮、少发生 1456 的可见消费，且感悟增量更高。这构成一条局部的参数内化证据。

四组都存活、饥饿 Normal、无新增伤口、家庭粮仓保持 30。纠错组随身粮食更少，仍存在 4 次多余购买；只支持事前定义的 10 天消费与成长目标，不代表长期最优或普遍生存能力。

NEGATIVE RESULT / 也保留

结构化经验组虽然结束钱数更多，但感悟增量从 16 降为 5 个百分点；未通过事前资源与成长联合标准，不能只挑财富指标宣称外化成功。

初轮失败与研究边界 ＋

初轮世界 31529 中，基座、文字经验、内化、模仿组结束钱数分别为 134 / 2 / 72 / 22，成长 shaping 均为 0.0005。修订协议在生成新测试世界 45931 之前登记。修订后仅覆盖一个新世界与训练 seed 731，不能据此得出跨世界或跨种子置信度结论。目标仍由研究者定义，采集仍有经验支架，并非纯自主探索；候选未发布为 Active，也未放行原 v0.5 生存 RL 门控。
